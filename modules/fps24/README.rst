24.00p
======

Records true 24.00p in 4K UHD instead of 23.98p.

- Set 4K UHD 23.98p and turn the entry ON.
- In Canon's Movie rec. quality menu set 24.00p to Enable.
- If it was already Enable, set Disable and Enable again.
- Canon's screens still say 23.98P. FHD stays 23.98p.
- First time may give Err 70: pull the battery.
- Not together with opengate.
