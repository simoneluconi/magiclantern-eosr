Open gate 4K
============

R6 1.9.0 only. Records the whole sensor height in 4K: the sensor reads all
its rows and the picture is developed and encoded at 4096x2736 (3:2),
HEVC 4:2:2 10-bit, level 6.1.

How to use: set Canon's movie size to 4K 25p, 29.97p or 23.98p with movie
crop off, enter movie mode once, then switch the entry ON and go to photo
mode once: the changes are applied there. Back in movie mode the camera
records open gate; the LCD shows the whole 3:2 frame.

Costs: the sensor runs like 4K 50p (more heat), the rolling shutter is that
of a full-height read, no 50/60p, HDMI output refused. Canon's player and
in-camera movie edit do not accept the clips.

Changing the movie size or fps, connecting HDMI or turning the entry off
removes every change (at the next photo-mode visit if movie mode is running).
Nothing changes while recording. The entry is always OFF after a restart.
